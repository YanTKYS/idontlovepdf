# idontlovepdf

自治体内で一般職員が利用することを想定した「PDF編集ツール」の検討リポジトリ。

## このリポジトリの現状

**現在は調査・PoC前段階であり、PDF編集ツール本体は実装していない。**

現時点で保存しているのは、実現可能性の検討経緯と技術判断の記録のみである。

## 目的

既存PDF内の本文テキストを直接編集する（修正 / 削除 / 置換）ツールの実現可能性を検討する。

テキスト追記、注釈追加、白塗り＋文字の重ね書きは、ここで言う「本文テキスト編集」に含めない。

ページ回転・ページ挿入・ページ削除は対象外である。

## 現時点の判定

**実現可能性あり（PoC未実施）**

技術的実現性と運用可否は分けて扱う。

| 区分 | 判定 | 根拠 |
|---|---|---|
| 技術的実現性 | 条件付きで可能 | 商用Web PDF SDK利用時。公式ドキュメント上の確認のみ |
| 運用可否 | 未判定 | 実機検証を行っていない |

技術的実現性の内訳は次のとおり。

| 条件 | 技術的実現性 |
|---|---|
| OSS・無償ライブラリのみ | 困難 |
| 商用Web PDF SDK利用可 | 条件付きで可能 |
| PDF.js / pdf-lib中心の自前実装 | 採用しない |

候補SDKの扱いは次のとおり。

| 候補 | 現在の扱い |
|---|---|
| Apryse WebViewer | 第一候補 |
| Foxit PDF SDK for Web | 第二候補 |

OSS（PDF.js / pdf-lib 等）だけでは、既存PDF本文の直接編集を安定して提供することは困難である。

一方、商用Web PDF SDKには既存本文の直接編集機能が製品機能として存在するため、実現可能性はある。

ただし「機能が存在すること」と「庁内で運用できること」は別である。日本語PDFでの編集品質、外部通信・ライセンス条件などは未確認であり、**運用可否は未判定**である。
